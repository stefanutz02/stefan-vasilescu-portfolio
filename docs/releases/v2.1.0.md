## 🔎 v2.1.0 — SEO overhaul & Romanian page

This release makes the site easier for search engines to understand and rank for **"Stefan Vasilescu"** / **"Ștefan Vasilescu"**. English and Romanian are now separate, indexable pages.

![Open Graph card](https://raw.githubusercontent.com/stefanutz02/stefan-vasilescu-portfolio/v2.1.0/public/og-image.jpg)

### 🎨 New features

- **Romanian page at [`/ro/`](https://stefanvasilescu.com/ro/).** It's pre-rendered in Romanian, so Google can index it on its own. English stays at `/`, and the two pages are linked with `hreflang` (`en`, `ro`, `x-default`)
- **URL-based language switch.** The EN/RO toggle in the header and the new English · Română links in the footer are real links, so crawlers can follow them. `<html lang>` matches the page language
- **New share images.** Redesigned Open Graph cards in English (`og-image.jpg`) and Romanian (`og-image-ro.jpg`)

### 🔍 SEO

- Each language has its own title, description, canonical URL, Open Graph and Twitter tags
- Titles lead with the name: *Stefan Vasilescu — Full-Stack Developer, CEO of Vesko Software* / *Ștefan Vasilescu — Dezvoltator Full-Stack, CEO Vesko Software*
- JSON-LD rebuilt around **`ProfilePage` → `Person`**: `alternateName` (Ștefan Vasilescu, stefanutz02), portrait `ImageObject`, home location, `worksFor` Vesko Software and Era Innovations, `sameAs` profiles, and an `ItemList` of projects
- `rel="me"` links to GitHub, LinkedIn and X
- `og:type` set to `profile`, with first name, last name and username

### 🐛 Fixes

- The sitemap listed `/#about`-style fragment URLs, which Google ignores. It now lists `/` and `/ro/` with hreflang and image entries
- Removed the link to a `favicon.ico` that didn't exist. Icons now come from `icon.svg` and the PNG favicons
- Era Innovations organization URL corrected from `.com` to `erainnovations.ro`
- Twitter/X handle is now `@stefanutz02` everywhere
- `robots.txt` cleaned up. `Crawl-delay` was removed because Google ignores it
- Web manifest: updated name and description, `theme_color` matches the dark theme, and icons no longer claim to be maskable

### 🔧 Under the hood

- `lib/seo.ts` is the single source of truth for per-language metadata and JSON-LD
- `components/HomePage.tsx` is shared by `app/page.tsx` (EN) and `app/ro/page.tsx` (RO)
- `LanguageProvider` reads the language from the URL (`usePathname`) instead of `localStorage`
- `public/.htaccess` now ships with the build: HTTPS and `www` → bare-domain redirects, 404 page, caching, compression and security headers
- README: DirectAdmin deploy steps and a new *Search engines* section

### 🚀 After deploying

1. Submit `https://stefanvasilescu.com/sitemap.xml` in Google Search Console
2. Request indexing for `/` and `/ro/`
3. Check the homepage in the [Rich Results Test](https://search.google.com/test/rich-results). It should show a **Profile page**
