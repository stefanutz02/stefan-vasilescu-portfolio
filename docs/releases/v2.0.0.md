## ✨ v2.0.0 — Glass redesign, dark & light themes

A full redesign of the portfolio. It uses the same glass design language as [vesko.ro](https://vesko.ro), keeps the chrome-purple identity, and adds a light theme next to the default dark one. It's still a single page, and all existing content was kept.

![stefanvasilescu.com v2: dark and light theme](https://raw.githubusercontent.com/stefanutz02/stefan-vasilescu-portfolio/v2.0.0/docs/screenshots/cover.webp)

### 🎨 New features

- **Dark-first theming + light mode.** A sun/moon toggle in the header. The choice is saved, applied before first paint (no flash), and updates the browser `theme-color`
- **Glass design system.** `.glass` / `.glass-strong` / `.glass-tint` surfaces, drifting aurora lighting, a masked grid background and a scroll progress bar
- **New hero.** A glass profile card with the portrait in a rotating chrome ring, status dot, Vesko / Era role tiles, floating chips and 3D tilt, plus a stats strip and an infinite technology marquee
- **New header.** A glass pill with a sliding active-section indicator, EN/RO switch, theme toggle and "Contact Me" CTA, plus a glass mobile menu
- **GitHub repos on projects.** Era Innovations links to [`era-innovations-website`](https://github.com/stefanutz02/era-innovations-website) and [`era-innovations-api`](https://github.com/stefanutz02/era-innovations-api). Obiectiv Imobiliare links to [`realty-pro`](https://github.com/stefanutz02/realty-pro). Cards show the repo count, and the modal has one Source button per repo
- **Redesigned sections.** Numbered About cards, a tilt-reactive technology grid, an Experience timeline with a sticky heading, Contact in one glass panel, and a footer that keeps the signature and adds section, company and social columns
- **Full Romanian coverage.** Project descriptions, About card titles and form placeholders are now translated

### 🐛 Fixes

- ERA Weather and Vesko Rover no longer show broken images. Projects without a screenshot get a branded gradient cover
- JSON-LD `sameAs` GitHub URL now points to `github.com/stefanutz02`
- Contact form submission no longer depends on the event object after `await`
- `<html lang>` now follows the selected language
- Romanian diacritics render in the brand fonts (`latin-ext` subsets)

### ♿ Accessibility

- Labelled form fields, keyboard-operable project cards, and a dialog that closes with Esc and locks page scroll
- `<noscript>` fallback that shows all animated content without JavaScript
- Visible focus rings and `prefers-reduced-motion` support across all motion primitives

### 🔧 Under the hood

- Theme colors live in CSS variables (`:root` for light, `.dark` for dark) and are exposed as Tailwind tokens (`ink`, `accent`, `line`, `surface`)
- Content moved to `lib/data.ts` (projects, repos, skills, socials, companies, API URL)
- Reusable motion primitives in `components/Motion.tsx` (`Reveal`, `Stagger`, `Tilt`, `Marquee`, `ScrollProgress`)
- Display font changed from Space Grotesk to **Plus Jakarta Sans**
- Removed `lenis`, `clsx` and `tailwind-merge`, plus the custom cursor and smooth-scroll components
- README rewritten with screenshots of both themes and mobile
